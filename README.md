# Level-1-IT-Support-Bot
This is my first crack at a bot.  This is a Level 1 Support Bot

## Project Summary

This project is a Level 1 IT troubleshooting chatbot built using Postman and the OpenAI API. The bot helps troubleshoot common enterprise IT support issues such as password resets, account lockouts, Outlook problems, Teams issues, VPN connectivity failures, Wi-Fi problems, MFA issues, and printer troubleshooting.

The project focuses on AI support workflows, prompt engineering, API testing, structured troubleshooting responses,  and security-safe AI behavior.

## Features

- Handles common Level 1 IT support issues
- Uses structured troubleshooting workflows
- Provides step-by-step troubleshooting
- Refuses unsafe credential requests
